Testing AI — backtest against a past season

Pick a season (1950, F1's first year, through 2025), then this picks a lineup using today's rules (salary cap, DK scoring, current driver salaries) and checks what it would have actually scored in every race that season we have real results for — using the genuine historical DK points from those races, not projections.
⚠ We don't have real historical DraftKings salaries or contest payouts for past races — DK doesn't archive old pricing, and this project only started saving weekly snapshots recently. So this uses today's salaries/cap as a stand-in for pricing in every past race tested. Scores shown are real historical points, not fabricated — but treat any "would this have made money" read as a rough proxy, not a real payout simulation. Also: race + DK data has only actually been fetched for a few recent seasons so far (see status below); most years in the dropdown won't have data yet until backfilled.
